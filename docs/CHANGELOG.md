# Changelog

本文件记录正式工程变更。更完整的产品开发过程见 `docs/obsidian-system-docs/开发历程与版本记录.md`，Git commit 是代码变更的主要事实来源。

## 2026-09-30

- 面后评价采用严格的岗位履职评分口径，区分个人执行、团队贡献和真实岗位要求；缺失信息不计低分。
- 默认保留简短结论，展开为岗位主题综合分析；评分标准与原话二次折叠，不再铺开分批对话。
- 实时追问改为简洁理解概括加针对性问题，保留独立原话依据和建议稳定性。
- 不改变混合面试模式、参考题可选原则、候选人状态或原有模型上下文限额。
