# Changelog

本文件记录正式工程变更。更完整的产品开发过程见 `docs/obsidian-system-docs/开发历程与版本记录.md`，Git commit 是代码变更的主要事实来源。

## 2026-10-19

- 新增 OpenCloudOS 9 单机准备脚本，保留完整 voice 依赖与系统文档目录，采用单进程应用和本机 PostgreSQL。
- 增加 root-only 生产配置初始化、systemd 守护和低内存参数、Nginx HTTPS/WebSocket 待配置模板。
- 增加本地增量文件备份、数据库归档校验与隔离临时库恢复验证；不自动迁移候选人数据、公开服务或调用付费 Provider。
- 新增凭据保留、敏感错误隐藏、备份失败与生产认证边界的离线检查。实际服务器执行结果另行记录，不将脚本存在等同于上线。
- 宝塔镜像过滤 Nginx 包时，提供独立 Caddy 准备、固定发布摘要与缓存二进制校验；保留原过滤规则。
- 记录本次 Windows / Linux 回归、空库备份恢复、代理准备和应用重启的实际结果；公网域名和真实 Provider 验收仍未完成。

## 2026-09-30

- 面后评价采用严格的岗位履职评分口径，区分个人执行、团队贡献和真实岗位要求；缺失信息不计低分。
- 默认保留简短结论，展开为岗位主题综合分析；评分标准与原话二次折叠，不再铺开分批对话。
- 实时追问改为简洁理解概括加针对性问题，保留独立原话依据和建议稳定性。
- 不改变混合面试模式、参考题可选原则、候选人状态或原有模型上下文限额。
