# 部署与故障排查

## 本地启动

Windows 可运行项目根目录的 `start-interview-copilot.cmd`，或在 `backend` 目录启动 Uvicorn。命令窗口需要保持开启。

默认访问地址：`http://127.0.0.1:8000/`

## 内网穿透能否用于上线

- 可以用于短期演示：把本机服务通过临时域名暴露给少量内部体验者，且不要放入真实简历、录音和逐字稿。
- 不可直接作为正式生产：免费快速隧道通常没有正式可用性承诺，本机休眠、断网或进程退出都会让系统不可用。
- 如过渡期确需隧道，应使用受管理的固定隧道、公司域名和身份访问策略；应用本身仍需飞书登录、HTTPS、数据库、持久化存储、备份、日志和故障恢复。
- 正式建议：应用运行在云服务器或托管容器，PostgreSQL 保存业务数据，对象存储保存录音，反向代理终止 HTTPS；隧道只能作为入口方案之一，不能替代服务器和数据治理。

## 上线前必做

1. 使用 PostgreSQL 替代单机 SQLite。
2. 配置 HTTPS 和正式域名。
3. 更换生产会话密钥。
4. 配置飞书 OAuth 回调地址与身份范围。
5. 配置录音文件的持久化存储和备份策略。
6. 评测并配置 ASR 与 LLM Provider。
7. 验证数据加密、访问权限、审计和到期清理。
8. 配置定时任务同步通知队列和到期预览，但发送与删除仍保留人工门槛。

## 试点就绪中心

管理员部署后先进入“招聘任务后台 → 试点就绪中心”，按页面顺序处理：

1. 生产运行模式、PostgreSQL、录音存储、HTTPS 与会话密钥。
2. 飞书 OAuth 与组织角色名单。
3. 腾讯云 ASR 和真实大模型。
4. Obsidian、飞书通知及后续北森接口。

连接测试不会返回密钥，也不会发送候选人数据。飞书测试只验证应用令牌，模型测试只发送固定探针；ASR 必须在字段检查后继续进行短音频实测。

## 常见问题

### 页面打不开

- 确认服务窗口仍在运行。
- 检查 8000 端口是否被多个旧进程占用。
- 确认访问的是当前服务地址，而不是腾讯云或飞书登录页面。

### 点击后没有反应

- 强制刷新浏览器，确保加载最新前端脚本。
- 检查当前登录角色是否有权限。
- 在服务日志中确认对应接口是否返回 200。

### 麦克风有录音但没有字幕

- 确认浏览器已授权麦克风。
- 查看页面 ASR 状态。
- 未配置或服务异常时，录音仍会继续，可使用人工逐字稿降级。

### 飞书通知无法发送

- 确认已添加机器人能力。
- 确认 `im:message:send_as_bot` 已审批并随应用版本发布。
- 检查服务器 App ID、App Secret、公开访问地址和消息开关。
- 在通知中心查看失败原因并人工重试。

### Obsidian 同步失败

- 确认 Vault 路径存在且可写。
- 确认目录包含 `.obsidian` 或 `首页.md`。
- 系统文档源文件必须包含隔离元数据，缺失时会阻止同步。
