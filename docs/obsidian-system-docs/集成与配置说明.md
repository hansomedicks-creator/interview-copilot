# 集成与配置说明

所有密钥只配置在服务器环境变量中，不写入浏览器、数据库或 Obsidian。

## 飞书登录

需要企业自建应用、OAuth 回调地址和用户身份读取权限。

配置项：

- `FEISHU_APP_ID`
- `FEISHU_APP_SECRET`
- `FEISHU_REDIRECT_URI`
- `FEISHU_OAUTH_SCOPES`
- `FEISHU_HR_OPEN_IDS`
- `FEISHU_ADMIN_OPEN_IDS`
- `INTERVIEW_SESSION_SECRET`

## 飞书通知

自建应用需要添加机器人能力，并开通 `im:message:send_as_bot` 应用身份权限。

配置项：

- `FEISHU_NOTIFICATIONS_ENABLED`
- `INTERVIEW_PUBLIC_BASE_URL`

系统只生成消息草稿，不自动发送；HR 选择具体消息并确认后才会调用飞书接口。

## 腾讯云实时字幕

配置项：

- `INTERVIEW_ASR_PROVIDER=tencent`
- `INTERVIEW_ASR_ENGINE_MODEL_TYPE=16k_zh_en_speaker_2.0`
- `TENCENT_ASR_APP_ID`
- `TENCENT_ASR_SECRET_ID`
- `TENCENT_ASR_SECRET_KEY`
- `TENCENT_ASR_HOTWORDS`（可选）

话者分离引擎返回 `speaker_id`，系统结合问答语义自动判断面试官与候选人。低置信度声源保持“待确认”，面试官可一键确认并回标本场历史字幕。未配置或实时 ASR 暂时不可用时，录音继续；人工逐字稿仍可作为降级入口。

## AI 模型

系统支持 OpenAI 兼容接口。

配置项：

- `INTERVIEW_PROVIDER_MODE=production`
- `INTERVIEW_LLM_BASE_URL`
- `INTERVIEW_LLM_API_KEY`
- `INTERVIEW_LLM_MODEL`
- `INTERVIEW_LLM_TIMEOUT_SECONDS`

远程模型异常或输出未通过证据校验时，自动降级到本地规则。

## Obsidian

配置项：

- `INTERVIEW_KNOWLEDGE_VAULT_DIR`
- `INTERVIEW_KNOWLEDGE_VAULT_NAME`

人才知识与系统文档使用不同目录和不同 `rag_scope`，避免运维说明参与候选人分析。

## 北森

当前支持北森历史样本导出文件的脱敏导入；实时接口与候选人阶段回写需等待管理员开放权限后再配置。
