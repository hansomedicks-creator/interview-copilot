# 数据治理与保留规则

## 保留期限

- 默认保留期限：90 天。
- 单次建档最长：180 天。
- HR 可以在建档时选择 3–6 个月范围内的期限。
- 首版不启用后台静默删除。

## 到期清理

HR 在“数据治理与审计”看到：

- 已到期候选人材料包
- 单独到期的录音
- 30 天内即将到期的材料

执行清理前必须选择具体候选人并二次确认。

## 清理内容

- 录音文件
- 逐字稿
- 逐字稿证据引用
- 报告中的证据原话
- 报告里的逐字稿和录音入口

## 保留内容

- 能力评分
- 各轮人工评价
- 最终流程决定
- 脱敏知识成果
- 操作审计记录

## 权限与审计

- HR/管理员可以查看治理中心。
- 面试官只能访问分配给自己的面试材料。
- 报告锁定、最终决定、录音/逐字稿下载、飞书发送、知识发布和到期清理需要审计。
- 审计日志不保存逐字稿内容或密钥。

## 系统文档隔离

本目录文档统一包含 `rag_scope: excluded` 和 `contains_pii: false`，用于产品使用与运维，不参与候选人能力分析。
